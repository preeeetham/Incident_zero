# INC-0002: Error rate on checkout

**Status:** resolved

The checkout service suffered a 100% error rate due to payment requests failing with invalid tokens, while the fraud-detection service experienced intermittent processing of asynchronous Kafka events. The incident was resolved by toggling a feature flag to turn off paymentFailure, after which all triggering signals cleared for two consecutive checks.
